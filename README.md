# Cube Mosaic Studio

Design pixel art for a grid of Rubik's cubes, then build it cube by cube.

**Use it:** https://ussens.github.io/cube-mosaic-studio/

## Features
- Paint, fill and pick-colour tools on a sticker-accurate board (default: 5 × 5 cubes, 3 × 3 stickers each)
- Mirror mode for symmetric designs; undo/redo (⌘Z / ⇧⌘Z)
- Import a photo and convert it to the six cube colours, with brightness, contrast and dither controls
- Build guide labelled A1–E5 showing each cube's face and which centre colour faces you; tick cubes off as you build
- Change the grid size or cube type (2×2 to 5×5)
- Designs save in the browser; copy a short design code to move a design between devices

## On iPad
Open the link in Safari, tap Share → Add to Home Screen.

Single self-contained `index.html`; no build step.
